# Roadmap

## Quick Wins

| Feature | Status | Notes |
|---|---|---|
| Arrow-Up to edit last message | ⬜ | Press ↑ in empty textarea to edit your last message |
| Escape key chain | ✅ | Cancel edit → cancel reply → mark as read |
| Draft persistence per channel | ✅ | Textarea content saved to localStorage per room |
| Markdown keybinds | ✅ | Ctrl+B/I/U/Shift+S |
| Typing indicator improvements | 🔄 | Better positioning and overflow handling |
| Member list online/offline colors | ✅ | Online = bright, Offline = muted |
| Character counter | ✅ | Appears at 80% of max length |
| Reaction count animation | ⬜ | Slide-up/down on count change |
